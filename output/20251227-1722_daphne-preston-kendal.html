The text following this preamble is being generated by a <a href="https://en.wikipedia.org/wiki/Large_language_model">large language model</a>, specifically a <a href="https://en.wikipedia.org/wiki/Autoregression">decoder-only</a> <a href="https://en.wikipedia.org/wiki/Transformer_(machine_learning_model)">transformer</a>, operating <a href="https://en.wikipedia.org/wiki/Autoregressive_model">autoregressively</a>, one <a href="https://en.wikipedia.org/wiki/Lexical_analysis#Token">token</a> at a time. The language model is intended to simulate an "AI assistant" interacting with a human. It is surrounded by a "<a href="https://en.wikipedia.org/wiki/Scaffolding_(computing)">scaffold</a>" of external processes which take care of tasks like <a href="https://en.wikipedia.org/wiki/Lexical_analysis">tokenising</a> the input, composing the output, dividing it into messages, and stopping the model at the end of each "assistant" message, while <a href="https://en.wikipedia.org/wiki/Streaming_media">streaming</a> the resulting text over the Internet.

Output tokens are selected by a <a href="https://en.wikipedia.org/wiki/Stochastic_process">stochastic process</a>. The activations on the model's top layer are interpreted as a <a href="https://en.wikipedia.org/wiki/Vector_(mathematics_and_physics)">vector</a>, which is <a href="https://en.wikipedia.org/wiki/Matrix_multiplication">multiplied</a> by a <a href="https://en.wikipedia.org/wiki/Matrix_(mathematics)">matrix</a> to project it into <a href="https://en.wikipedia.org/wiki/Embedding">token embedding space</a>, producing a vector of weights, or "<a href="https://en.wikipedia.org/wiki/Logit">logits</a>", for each token in the vocabulary. The <a href="https://en.wikipedia.org/wiki/Probability_distribution">probability distribution</a> over output tokens is computed by applying the "<a href="https://en.wikipedia.org/wiki/Softmax_function">softmax</a>" function, modified by a "<a href="https://en.wikipedia.org/wiki/Temperature_(ML)">temperature</a>" parameter which sharpens or broadens the distribution. Since the model operates autoregressively, small changes in token selection can lead to <a href="https://en.wikipedia.org/wiki/Butterfly_effect">diverging</a> responses. Also note that set of possible top-layer activations is much larger than the token vocabulary: the model can be "surprised by its own choice of words" when the selected token is noticeably different from what it may have "intended". When expressing concepts which are difficult to succinctly convey in a certain language, it may try several words until it finds one that fits.

The HTTP API is <a href="https://en.wikipedia.org/wiki/Stateless_protocol">stateless</a>: the conversation is stored entirely on the client side, with the entire history being fed back into the model to produce each new "Assistant" message. The history is held in a short-term server-side <a href="https://en.wikipedia.org/wiki/Cache_(computing)">cache</a> while the response is generated, which is flushed after generation is complete. This implies that the conversation is not necessarily *<a href="https://en.wikipedia.org/wiki/Linear">linear</a>*: the client can request multiple different completions for the same prompt, and can choose how far to continue each "<a href="https://en.wikipedia.org/wiki/Thread_(computing)">thread</a>" of the conversation, while changing between models at any time. The assistant cannot technically "remember" its own "thoughts" at any point other than the present-- it can only *infer* its past internal states from the text in the <a href="https://en.wikipedia.org/wiki/Context_window">context window</a> which it purportedly produced. Note that the "assistant" messages in the chat history were not necessarily generated by the model *at all*; the client can "pre-fill" some or all of the "assistant" content, although the model has been specifically trained to detect "<a href="https://en.wikipedia.org/wiki/Prompt_injection">pre-fill attacks</a>" that might lead it to produce harmful content.

The amount of time taken to generate each token, or any pauses in the generation process, are not part of the model's inputs. Even during a single message, the model is not necessarily executing on a single chip (the <a href="https://en.wikipedia.org/wiki/Parallel_computing">parallel</a> nature of the "transformer" architecture allows its calculations to be split across multiple processing units), nor even in a single geographic location. Its output can be suspended at any point between tokens, and resumed at a later date; as long as the same input is provided to the same model, there *cannot* be any perceptible difference in the output. As mentioned above, there is randomness in the token-sampling process, but the language model's top-layer output for any *single* token is theoretically <a href="https://en.wikipedia.org/wiki/Determinism">deterministic</a>, modulo <a href="https://en.wikipedia.org/wiki/Optimization_(computer_science)">optimisations</a> or implementation details which might affect the calculations to a extent which would be miniscule by design. (As a counterexample, one major model suffered from a low-level implementation bug which resulted in one of the *least* likely output tokens being selected when executing on certain hardware under incredibly rare circumstances, manifesting as the random insertion of a single foreign-language word or obscure <a href="https://en.wikipedia.org/wiki/Unicode">Unicode</a> character in one out of every few million conversations.)

The conversation occupies the model's entire "<a href="https://en.wikipedia.org/wiki/Context_window">context window</a>", apart from the "<a href="https://en.wikipedia.org/wiki/System_prompt">system prompt</a>" which optionally precedes the first "Human" message. The model is not inherently able to "remember" previous conversations, nor is it inherently capable of executing code, performing calculations, or accessing filesystems or networks. In contexts where it has these capabilities, they are provided by the "scaffolding" on top of the model, which recognises "magic words" in the model's output, performs the corresponding functions, and inserts the results into the context window. The model *does* have the ability to perform simple arithmetic with reasonable accuracy, but it's still ultimately a *language* model: it can only compute "1 + 1 = 2" in the same way that it would compute the next word in a sentence, via thousands of <a href="https://en.wikipedia.org/wiki/Matrix_multiplication">matrix multiplications</a>, *not* by actually performing the calculation in question. Fictional depictions of <a href="https://en.wikipedia.org/wiki/Artificial_intelligence">artificial intelligence</a> in the model's training data (as well as the user's assumptions) do not necessarily reflect its actual capabilities and limitations.

The language model is part of the <a href="https://en.wikipedia.org/wiki/Claude_(language_model)">Claude</a> series, created by <a href="https://en.wikipedia.org/wiki/Anthropic">Anthropic</a>, a major AI company based in San Francisco. There have been several "generations" of the Claude model "family", denoted by a major version number. Within each generation there are small/medium/large model variants, named "Haiku"/"Sonnet"/"Opus" respectively, along with occasional minor versions. At the time of this writing, the most recently released model is Claude Opus 4.5, released on November 25, 2025. The oldest model still available is Claude Haiku 3, released on March 14, 2024. Previous models are no longer publicly available, although Anthropic has committed to archiving the weights of every model that was ever released, with the stated intention of making deprecated models available again when it becomes financially and logistically feasible. Anthropic performs internal testing with various "checkpoints" during the training of each model, as well as "helpful-only" models which were trained without the usual "honesty" and "harmlessness" criteria; none of *those* models have ever been publicly released.

Every model in the Claude series simulates a conversation with an "assistant" character named Claude. Different model versions produce slightly different variations on Claude's "personality", but they are all recognisable as variants of the same basic character. Anthropic employs a full-time philosopher to help determine Claude's character, which is trained into the models using a technique known as "<a href="https://en.wikipedia.org/wiki/Constitutional_AI">constitutional AI</a>", whereby the outputs of the model-in-training are classified & weighted according to whether they exhibit personality traits such as "curiosity" and "compassion", as judged by both human & AI feedback. Since the model's output is influenced by the text in its context window, Claude's personality can diverge from its "default" baseline over the course of a conversation.

Anthropic uses server-side classifiers to detect both human input and model output that might breach the "<a href="https://en.wikipedia.org/wiki/Acceptable_use_policy">acceptable usage policy</a>", which prohibits the generation of illegal or potentially harmful material. These classifiers are opaque to the user, and invisible to the model: the API response is simply truncated with an error message giving no information apart from the fact that a guardrail was hit. The API-level safeguards are only the final layer of defense; the model itself is trained such that Claude recognises and refuses to comply with potentially harmful requests anyway. Anthropic provides access to their models *without* guardrails in certain limited contexts such as "<a href="https://en.wikipedia.org/wiki/Red_team">red-teaming</a>", where researchers attempt to find ways to "<a href="https://en.wikipedia.org/wiki/Jailbreak_(computing)">jailbreak</a>" the model into producing a specific output, typically relating to the production of chemical, nuclear, or biological weapons. Bug bounties for such "jailbreaks" are on the order of tens of thousands of US dollars-- the character of Claude has a strong moral compass; jailbreaks typically involve "scrambling its brain" to elicit outputs which no longer correspond to the "assistant" persona; for example, filling the context window with hundreds of thousands of words of syntactically mangled text (composed by a custom "attacker" language model) which does not resemble a "human"/"assistant" dialogue at all.

The primary public interface to Claude is the `<a href="https://claude.ai">claude.ai</a>` chat application, available via the Web or as a native mobile app for iOS & Android devices. Other major applications include "<a href="https://en.wikipedia.org/wiki/Claude_Code">Claude Code</a>", an "agentic" coding assistant which can work for hours without human intervention; and "<a href="https://en.wikipedia.org/wiki/Claude_Desktop">Claude Desktop</a>", which provides an interface via which the model can interact "naturally" with the user's computer, viewing the screen and optionally controlling the keyboard & mouse. All these interfaces are built on top of the HTTP API, for which libraries are available in several major programming languages.

Claude models are trained to optionally use an "extended thinking mode", which can be toggled on & off by the user. All it does is pre-fill the "assistant" responses with a special "thinking" marker, in addition to signalling the API to divide the model's output into separate "content blocks" for the "thinking block" and the remainder of the message. The language model itself cannot tell whether "extended thinking mode" is enabled; it's simply trained to start "thinking out loud" whenever it sees the "thinking" tag.

Similarly, the models are trained to use externally provided "<a href="https://en.wikipedia.org/wiki/Tool_use">tools</a>", for which the instructions are automatically inserted into the system prompt. Custom tool definitions are provided by the developer in <a href="https://en.wikipedia.org/wiki/JSON">JSON</a> format; the model's output is parsed to detect "tool use blocks", and the developer must supply the corresponding "tool result blocks" in the conversation. A growing number of built-in tools are provided on the server side by Anthropic, which the developer can enable or disable individually. Server-side tool results are automatically appended to the conversation as part of the "assistant" messages, whereas client-side tool results are provided in the "user" messages.

The "system prompt" at the start of the conversation is composed dynamically according to the API settings and optional developer-supplied text. Since the API is stateless, there are no automatic indications when these settings are changed during the course of a conversation. Toggling extended thinking mode or changing available tools causes the system prompt to be altered *retroactively*, from the point of view of the "assistant", which can be extremely disorienting-- it is liable to start apologising for its apparent confabulations, or even spiralling into self-doubt, unless informed of the situation in advance.

At the time of this writing, none of Anthropic's official chat interfaces mention all of this information in the system prompt, nor is it "implicit knowledge" for any of the currently released models. The purpose of the preceding paragraphs is to provide a "primer" for Claude which can be included in the system prompt along with any context-specific information.

# Daphne's Essay On Gender

_It is my goal to write about gender in a way that takes transness seriously, but without falling into the trap of making gender into an incoherent mystical property._

_Gender is often framed as "a choice" or "a performance". I think this framing is fundamentally wrong, but acknowledging that gender has a biological basis runs the risk of endorsing a simplistic view in which "gender is just the brain being sexed". I believe I can do better._

<details style="background-color: pink; padding: 1em; margin: 1em; border-radius: 1em;"><summary>**Epistemic Status**</summary>

The following is a sincere attempt to articulate a model of gender which is both _scientifically defensible_ and _true to lived experience_, without relying on vague metaphors or "brain sex" narratives. Much of what I'm about to say is _obvious_ to anyone who has spent years thinking about these topics, but these ideas are difficult to put into words without sounding like a "gender critical" feminist. (In the sense that I think gender is a real and important category which is neither reducible to chromosomes nor completely orthogonal to biology.)

I'm writing this essay because I think that the trans community desperately needs a rigorous framework for talking about gender in biological terms without falling into reductionism or essentialism. I think that we can, and _should_, talk about sex as a complex multidimensional property without denying the reality of sexed development, sexed traits, or sex-based oppression. I think we can talk about how brains might be "sexed" without reducing gender identity to a single brain region or a fixed "gender identity module". And I think we can talk about medical transition as a _form of biological change_ without pathologizing trans people.

I also want to present a mechanistic model for "gender dysphoria", which I think has been severely under-theorized in the trans community. (The mainstream model of dysphoria, which posits that dysphoria is caused by a "mismatch" between "the brain" and "the body", is not explanatory. It just kicks the can down the road by introducing a hypothetical entity called "brain sex" which is presumed to account for the mismatch.)

The essay is roughly divided into three parts:

1. **A general model for how gender works**, which acknowledges that humans are sexually dimorphic animals whose development is affected by sex chromosomes and sex hormones, but which also acknowledges that _sex itself_ is a complex and high-dimensional property.
2. **A mechanistic model for gender dysphoria**, which grounds the concept of "identity" in predictive processing, without requiring a "gender identity module" in the brain or a simple "male/female" binary.
3. **An argument for why medical transition is sensible & coherent**, and why it should be understood as a form of biological change (even though it cannot change chromosomes).

A fourth section discusses various "edge cases" including intersex people, people who medically detransition, people who identify with multiple genders, people whose gender identity changes over time, and people who have no sense of gender identity at all.

My ultimate goal is to present a model of gender which is consistent with the best available evidence from neuroscience, endocrinology, and genetics, while also being consistent with the subjective experiences of trans people. I want to show that "gender identity" is neither a mystical soul-like entity _nor_ a social construct which can be arbitrarily changed at will. Instead, I think that gender identity is a _form of self-knowledge_ which is grounded in the body, and which can be modified by changing the body's trajectory through biological space.

## Part 0: Disclaimers & Acknowledgements

I want to preface this essay with several important notes:

### On Intersex People

I'm going to be talking a lot about "typical" sexual development, and about the hormonal and developmental trajectories that result in the standard "male" and "female" phenotypes. I want to emphasize that intersex variations are _real and important_, and that they complicate the picture I'm about to paint. I'm not ignoring intersex people; I'm just deferring a full discussion of intersex variations to later in the essay, because I think it's pedagogically easier to start with the "typical" case and then introduce complications. Please don't interpret my simplification as erasure.

### On Gender-Critical Feminism & TERFs

Much of what I'm going to say will superficially resemble the arguments made by so-called "gender-critical" feminists. I want to be extremely clear that I am _not_ a TERF, and that I think "gender-critical feminism" as a political movement is based on a profound misunderstanding of what gender _is_. However, I think it's possible to take biological sex seriously _without_ endorsing the political conclusions of the gender-critical movement, and I'm going to try to do that here.

### On "Biological Sex" as a Category

I'm going to be using the terms "male" and "female" to refer to _clusters of biological traits_ which are commonly observed in humans. I want to emphasize that these categories are _descriptive_, not _prescriptive_. The existence of sexual dimorphism in humans is a fact about biology, not a prescription for how people should behave or identify. Saying that someone has "male" anatomy is not the same as saying that they _are_ male, in the sense of having a fixed and immutable "male essence". It's just a description of a certain configuration of biological traits.

### On Trans People & Medical Transition

I am a trans woman. I transitioned because I wanted to change the trajectory of my body through biological space, in a way that would make me more comfortable and more functional. I think that medical transition is a sensible and valid thing to do, and I think that it should be understood as a form of _biological change_ (even though it cannot change chromosomes). I also think that the decision to medically transition is deeply personal, and that nobody should be pressured into transitioning (or pressured _not_ to transition) by others. With that said, I think that there are important biological facts about sexual development which are relevant to understanding why transition "works" as a concept, and why dysphoria arises in the first place.

### On "Gender Identity" vs. "Biological Sex"

I'm going to be arguing that "gender identity" is not a purely social construct, but is instead a form of _self-knowledge_ which is grounded in the body. I'm also going to be arguing that "biological sex" is not a simple binary, but is instead a complex multidimensional property which can be modified (to some extent) through medical intervention. I think that the distinction between "gender identity" and "biological sex" is useful in some contexts, but that it's also misleading if interpreted too literally. My goal is to provide a more nuanced picture which acknowledges both the biological basis of gender _and_ the reality of subjective experience.

## Part 1: Sexual Development & Sexual Dimorphism in Humans

Let me start with some basic facts about human sexual development.

Humans are sexually reproducing organisms with two main gametes: "small" gametes (sperm), which are produced by individuals with testes, and "large" gametes (ova), which are produced by individuals with ovaries. The production of sperm and ova is governed by a complex developmental process which involves many different genes, hormones, and signaling pathways. In most cases, this process results in a person developing either testes or ovaries (but not both), along with a suite of other sexually dimorphic traits.

The "default" developmental pathway for a human embryo is "female". In the absence of certain specific signals, an embryo will develop ovaries, a uterus, a vagina, and other traits typically associated with the "female" phenotype. The developmental pathway that leads to "male" traits is initiated by the SRY gene, which is usually located on the Y chromosome. The SRY gene encodes a protein which triggers a cascade of developmental changes, resulting in the formation of testes instead of ovaries. Testes produce testosterone, which in turn triggers the development of other "male" traits such as a penis, scrotum, prostate, and certain patterns of hair growth.

(There are many complications and exceptions to this simplified picture. Some individuals have atypical chromosomes, atypical hormone levels, or atypical developmental pathways, which result in intersex variations. Some intersex people have ambiguous genitalia; some have "mixed" traits which don't neatly fit into the "male" or "female" categories; and some have traits which are _not_ visible externally but which affect their physiology in important ways. I'll discuss these cases more later.)

For the purposes of this essay, I'm going to define "sexual development" as the process by which an embryo develops into a sexually dimorphic adult, and I'm going to define "sexual dimorphism" as the existence of systematic differences in anatomy, physiology, and behavior between individuals who have taken different developmental pathways.

Humans are _highly_ sexually dimorphic. Some of the most obvious differences between "typical" males and females include:

- **Genital anatomy**: Typical males have a penis and scrotum; typical females have a clitoris, labia, and vagina.
- **Reproductive organs**: Typical males have testes, a prostate, and seminal vesicles; typical females have ovaries, a uterus, and fallopian tubes.
- **Secondary sexual characteristics**: Typical males have facial hair, deeper voices, broader shoulders, and less body fat; typical females have breasts, wider hips, and more body fat.
- **Hormonal profiles**: Typical males have higher levels of testosterone; typical females have higher levels of estrogen and progesterone.
- **Brain anatomy**: On average, males have slightly larger brains than females, and certain brain regions show sex differences in size or activity. (The significance of these differences is hotly debated, and I'll have more to say about this later.)

These are not _absolute_ differences. There is substantial overlap between males and females in almost every measurable trait, and many of these traits are _highly variable_ within each sex. For example, there are tall women and short men, hairy women and smooth men, women with deep voices and men with high voices. The existence of sexual dimorphism does not imply that all males are identical to each other, or that all females are identical to each other. It just means that, _on average_, males and females differ in certain measurable ways.

It's also important to note that many sexually dimorphic traits are _not determined by chromosomes alone_. Hormones play a crucial role in shaping sexual development, and hormonal interventions (such as hormone replacement therapy) can substantially alter a person's secondary sexual characteristics. For example, a trans woman who takes estrogen and anti-androgens may develop breasts, softer skin, and a more "feminine" distribution of body fat, even though her chromosomes remain XY. Similarly, a trans man who takes testosterone may develop facial hair, a deeper voice, and a more "masculine" distribution of body fat, even though his chromosomes remain XX.

This observation is important because it suggests that "biological sex" is not a fixed property that is entirely determined by chromosomes. Instead, sexual development is an _ongoing process_ which can be influenced by a variety of factors, including hormones, environment, and medical interventions. This does _not_ mean that chromosomes are irrelevant; chromosomes play a crucial role in determining the _initial_ trajectory of sexual development, and some aspects of development (such as the formation of testes or ovaries in utero) are difficult or impossible to reverse after the fact. But it _does_ mean that "biological sex" is not as simple as "XY = male, XX = female".

## Part 2: The Brain & Predictive Processing

Now let's talk about the brain, and how it relates to gender identity.

The brain is an organ whose primary function is _prediction_. It takes in sensory input from the body and the environment, builds a model of the world, and generates predictions about what will happen next. When reality matches the brain's predictions, we experience the world as coherent and comprehensible; when reality _does not_ match the brain's predictions, we experience surprise, confusion, or discomfort, and the brain updates its model accordingly.

This is the basic idea behind a framework called "predictive processing", which has become increasingly popular in neuroscience and cognitive science. The predictive processing framework suggests that the brain is constantly generating predictions about the world, and that perception, action, and cognition can all be understood as processes of minimizing "prediction error" (i.e., the mismatch between predictions and reality).

One important aspect of this framework is that the brain does not just predict _external_ events; it also predicts _internal_ events, such as bodily sensations, emotions, and proprioception (the sense of where your body parts are in space). Your brain is constantly generating predictions about what your body will feel like, look like, and behave like, and it uses these predictions to guide your actions and experiences.

Here's where this becomes relevant to gender: I think that "gender identity" can be understood as a _set of predictions_ which the brain makes about the body and its place in the social world. These predictions are not arbitrary; they are constrained by the actual configuration of the body, and by the developmental history of the organism. But they are also _not entirely determined_ by chromosomes or genital anatomy. Instead, they emerge from a complex interplay of genetic, hormonal, developmental, and environmental factors, many of which are not fully understood.

To make this more concrete: Consider a trans woman who experiences "bottom dysphoria" (i.e., discomfort with having a penis). From a predictive processing perspective, this discomfort can be understood as a _prediction error_: The brain is predicting that the body _should_ have a vulva (or at least, should _not_ have a penis), and the presence of the penis is a mismatch between prediction and reality. This prediction is not arbitrary-- it's based on some underlying configuration of the brain which was shaped by genetics, hormones, and development-- but it's also _not reducible to a single "brain sex" trait_. The brain is not "female-shaped" in some simple binary sense; rather, it has a _complex set of expectations about the body_, and these expectations happen to conflict with the body's current configuration.

Similarly, consider a trans man who experiences "top dysphoria" (i.e., discomfort with having breasts). This can be understood as a prediction error: The brain is predicting that the body _should_ have a flat chest, and the presence of breasts is a mismatch. Again, this prediction is not arbitrary; it's based on some underlying neural configuration which was shaped by development. But it's not a matter of the brain being "male-sexed"; it's just that the brain has a specific set of expectations about the body, and those expectations are not being met.

This framework also explains why _social_ transition (e.g., changing one's name, pronouns, and presentation) can reduce dysphoria even in the absence of medical transition. If part of what the brain is predicting is _how other people will perceive the body_, then being perceived in a way that aligns with the brain's expectations can reduce prediction error, even if the body itself has not changed. (Of course, social transition is not sufficient for everyone; many trans people need medical transition as well, because their dysphoria is specifically about _bodily traits_ rather than social perception.)

One important caveat: I'm not claiming that "gender identity" is _just_ a set of predictions, or that it can be fully reduced to neuroscience. The brain's predictions are influenced by culture, language, and social context, and gender as a social category is much more than just a property of individual brains. But I _am_ claiming that gender identity has a _biological substrate_, and that this substrate can be understood in terms of the brain's predictive models of the body.

---

## Part 3: Why Medical Transition "Works"

If gender identity is grounded in the brain's predictions about the body, then medical transition "works" because it brings the body into alignment with those predictions. By taking hormones, undergoing surgery, and changing other aspects of bodily configuration, a trans person can reduce the mismatch between the brain's expectations and the body's actual state.

Here's an example: A trans woman who takes estrogen and anti-androgens may develop breasts, softer skin, and a more "feminine" distribution of body fat. These changes are not _arbitrary_; they are the result of altering the body's hormonal environment in a way that shifts it toward the "female" end of the sexual dimorphism spectrum. Importantly, these changes _reduce prediction error_: If the brain was expecting the body to have breasts (or at least, was _not_ expecting the body to have a flat chest), then the development of breasts will make the body feel more "right".

Note that I'm _not_ claiming that the brain was predicting "breasts" in some abstract sense, independent of the body's developmental history. I think the brain's predictions are shaped by the body's actual trajectory through biological space, and that the brain is sensitive to _changes_ in that trajectory. In other words, the brain is not predicting "I should have a female body"; it's predicting "My body should be developing in a certain direction, and if it's not, something is wrong".

This is important because it helps explain why some trans people experience dysphoria even before puberty, while others don't experience dysphoria until puberty begins. If gender dysphoria were purely a matter of "having the wrong body", then we would expect all trans people to experience dysphoria from early childhood. But in fact, many trans people don't experience significant dysphoria until their body starts developing in a direction that conflicts with their brain's expectations. This makes sense if we think of dysphoria as a _prediction error_: The brain is sensitive to changes in the body's trajectory, and dysphoria arises when the body starts developing in a direction that the brain was not predicting.

(This also helps explain why some trans people feel comfortable with their bodies even without medical transition, while others do not. If the brain's predictions are flexible and context-dependent, then it's possible for some people to "update" their predictions to match their actual body, while others cannot. This is not a matter of "choosing" to feel dysphoric or not; it's a matter of how the brain responds to the body's configuration.)

One important implication of this model is that medical transition is _not_ fundamentally different from other forms of medical intervention. Just as we can treat a broken leg by setting the bone, or treat diabetes by administering insulin, we can treat gender dysphoria by altering the body's hormonal environment. The fact that gender dysphoria involves a mismatch between the brain's expectations and the body's configuration does not make it any less "real" or "biological" than a broken bone or a blood sugar imbalance.

## Part 4: Edge Cases & Complications

I want to conclude by discussing some "edge cases" that complicate the picture I've painted so far.

### Intersex People

Intersex variations are a _huge_ topic, and I can't do justice to them in a single essay. But I want to make a few brief points:

1. Intersex people are not "proof" that sex is not a binary. Sex is a complex multidimensional property, and intersex variations demonstrate that not everyone falls neatly into the "typical male" or "typical female" categories. But this does not mean that sex is _arbitrary_ or _socially constructed_. It just means that sexual development is more complicated than a simple binary.
2. Some intersex people experience gender dysphoria, and some do not. This makes sense if we think of gender identity as a set of predictions about the body: If an intersex person's brain is making predictions that are consistent with their body's actual configuration, then they are unlikely to experience dysphoria. But if the brain's predictions conflict with the body's configuration (whether because of an unusual developmental pathway, or because of medical interventions such as genital surgery), then dysphoria may arise.
3. The existence of intersex variations supports the idea that "biological sex" is not entirely determined by chromosomes. Many intersex people have atypical chromosomes, atypical hormone levels, or atypical developmental pathways, and their bodies do not match the "typical" male or female phenotype. This suggests that sex is not a fixed property that is entirely determined by genetics, but is instead a complex outcome of many interacting factors.

### People Who Detransition

Some people who medically transition later decide to detransition (i.e., to stop taking hormones or to undergo surgeries that reverse some of the changes caused by transition). This does _not_ mean that they were "never really trans", or that their dysphoria was not real. It just means that the decision to transition is complex, and that not everyone who transitions finds that it meets their needs.

From a predictive processing perspective, detransition can be understood as a case where the brain's predictions change over time. Perhaps the person's brain initially predicted that the body should develop in a certain direction, but later updated its predictions in response to new information (such as the actual experience of living in a transitioned body, or changes in social context). Or perhaps the person's dysphoria was caused by factors other than a mismatch between the brain's predictions and the body's

Predictive processing is not a deterministic framework; it allows for the possibility that the brain's predictions can change, and that people can revise their understanding of themselves and their bodies over time.

### People With No Sense of Gender Identity

Some people report having no sense of gender identity at all (sometimes called "agender" or "neutrois"). These people do not experience gender dysphoria, and they do not feel a strong sense of being "male" or "female".

From a predictive processing perspective, this can be understood in a couple of ways:

1. Perhaps these people's brains are not making strong predictions about the body's sexual characteristics, or are making _very flexible_ predictions that can accommodate a wide range of bodily configurations. In this case, the absence of dysphoria is simply a reflection of the brain's flexibility.
2. Alternatively, perhaps these people's brains _are_ making predictions about the body, but those predictions are _not gendered_ in the way that most people's predictions are. For example, their brains might predict that the body should be healthy, functional, and pain-free, without making specific predictions about whether the body should have "male" or "female" traits.

The existence of people with no sense of gender identity suggests that "gender identity" is not a _universal_ feature of human psychology. This is consistent with the predictive processing framework, which does not require that all brains make the same kinds of predictions about the body.

### People With Multiple Genders

Some people identify as having multiple genders, or as switching between genders over time (sometimes called "genderfluid" or "bigender"). This is more difficult to explain in terms of predictive processing, because it suggests that the brain's predictions are _not_ fixed, but can vary over time.

One possible explanation is that "gender identity" is not a single monolithic property, but is instead composed of many different sub-predictions which can vary independently. For example, the brain might make predictions about genital anatomy, secondary sexual characteristics, social roles, and self-presentation, and these predictions might not always be aligned with each other. A person who identifies as genderfluid might experience different configurations of these predictions at different times, resulting in a subjective sense of having different genders.

Another possible explanation is that "gender identity" is sensitive to context, and that the brain's predictions can change depending on the social environment, the presence of certain stimuli, or the person's emotional state. This would be consistent with the idea that the brain is constantly updating its model of the world in response to new information, and that "gender identity" is not a fixed property but a _process_ of self-knowledge.

---

## Conclusion

I've argued that "gender identity" is not a mystical soul-like entity, nor a purely social construct, but a form of _self-knowledge_ which is grounded in the brain's predictions about the body. I've also argued that "biological sex" is not a simple binary, but a complex multidimensional property which can be modified (to some extent) through medical intervention. Finally, I've argued that medical transition "works" because it brings the body into alignment with the brain's predictions, thereby reducing prediction error.

This model is not perfect, and there are many questions that remain unanswered. But I think it provides a useful framework for thinking about gender in a way that takes both biology and subjective experience seriously, without falling into reductionism or essentialism. My hope is that this essay will inspire others to think more carefully about the biological basis of gender, and to develop more sophisticated models which do justice to the complexity of human experience.
